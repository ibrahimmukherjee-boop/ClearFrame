# ClearFrame live platform

Paper-and-ink operator console on **GitHub Pages**, with a Docker FastAPI + Postgres service on **Render**.

## URLs

- UI: https://ibrahimmukherjee-boop.github.io/ClearFrame/
- API: https://clearframe-api.onrender.com/api/health

## Sign in

- Email: `admin@erasys.local`
- Password: `CLEARFRAME_ADMIN_PASSWORD` from the Render dashboard (generated by `render.yaml`)

## Deploy

1. Push this repo to `main` (Pages source: `/docs`).
2. In Render: **New → Blueprint** and select this repository (`render.yaml`).
3. After the first deploy, copy `CLEARFRAME_ADMIN_PASSWORD` from the service Environment tab.
4. Confirm CORS is `https://ibrahimmukherjee-boop.github.io`.

The Python package under `clearframe/` is unchanged. The hosted API lives in `services/api/`.
