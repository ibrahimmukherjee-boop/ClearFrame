ClearFrame — Desktop Package Setup
==================================
Version: SDK 0.2.1 / API 2.1.0-enterprise
License: Apache 2.0 (ClearFrame OSS)

WHAT'S IN THIS ZIP
------------------
clearframe/          Python SDK (pip-installable package)
services/api/        FastAPI control plane + vendored SDK
docs/                Console UI (GitHub Pages)
deploy/              Kubernetes manifests
docker-compose.yml   Local API + Postgres
DEPLOYMENT.md        Production env vars & connectors
README.md            Product overview

REQUIREMENTS
------------
- Python 3.11 or 3.12
- pip
- (Optional) Docker + Docker Compose for full stack
- (Optional) Postgres 16 for production-shaped local run
- (Optional) Ollama / OpenAI / Anthropic keys for live LLM calls

QUICK START — SDK
-----------------
cd clearframe
python3 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -e ".[dev]"
clearframe version          # → ClearFrame v0.2.1
clearframe init my-agent
pytest -q

QUICK START — API + Console
---------------------------
# Option A: Docker
docker compose up --build
# API: http://localhost:8080/api/health

# Option B: Local Python
cd services/api
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # fill secrets for production
CLEARFRAME_ENV=development CLEARFRAME_AUTH=true USE_OLLAMA=false \
  USE_CLEARFRAME_OPS=false CLEARFRAME_API_PORT=18080 python run.py
# Dev login: admin@erasys.local / admin
# Open docs/index.html or the hosted demo:
# https://ibrahimmukherjee-boop.github.io/ClearFrame/
