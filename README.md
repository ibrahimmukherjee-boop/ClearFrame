# ClearFrame

Open-source agent protocol (`clearframe/`) plus a hosted operator platform:

- **GitHub Pages console:** [`docs/`](docs/) — paper/ink UI  
  Live: https://ibrahimmukherjee-boop.github.io/ClearFrame/
- **Render API:** [`services/api/`](services/api/) — FastAPI, Postgres, Aegis, SafePulse, TrustRegistry, Sonar  
  Blueprint: https://dashboard.render.com/blueprint/new?repo=https://github.com/ibrahimmukherjee-boop/ClearFrame

The root `clearframe/` Python package is unchanged. Operator APIs live under `services/api/`.
